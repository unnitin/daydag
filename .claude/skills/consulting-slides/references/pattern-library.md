# Pattern library: which slide shape for which message

Pick the pattern from the message, then build it (see `build.md`) or copy it from one of
Nitin's three template decks in `${SLIDE_TEMPLATES_DIR}` (from `.env`):

- **K** = `Slide examples_Killer slides_Final.pptx` (101 slides, filled examples with real
  action titles; the best reference for what a finished slide looks like)
- **S** = `Sample killer slides 2020 selection.pptx` (159 slides, layout patterns with
  placeholder text; he also keeps a renamed copy as a working deck)
- **G** = `German PP Templates.pptx` (151 slides, data-heavy tables, charts, comparisons,
  lists; 2016)
- **P** = `Consulting patterns - data and AI.pptx` (19 slides, generated by this skill's
  `assets/patterns_build.js` with `bcg_style.js`; placeholder text and no third-party
  branding, so copy freely). It holds the patterns the three libraries lack, listed below.

All four share the same look: Trebuchet MS, 13.33 x 7.5 in, green on grey. Slide numbers
below are positions in the file (`catalog_template.py` prints them with their titles).

## The generated deck, slide by slide (P)

Patterns that recur in a change proposal and that none of the libraries has. Each is one
helper call or a few, so the build script is the better copy than the slide.

| P | Pattern | Build |
|---|---|---|
| 3 | Situation: three stat cards, the costs beneath | `cards`, `columns`, `text` |
| 4 | Evidence: four dated cards, one event and what it tells you each | `cards` |
| 5 | Two costs: a number on the left, the missed opportunities on the right | `twoCols`, `bigNumber`, `barsH`, `execSummary`, `takeaway` |
| 8 | Principles: six cards, each with the failure it stops and its status | `cards` |
| 10 | Capabilities: three cards and a proof panel | `cards`, `boxPanel` |
| 11 | Audiences: six cards with status, and the entry points beneath | `cards`, `text` |

P was generated on 2026-10-10, before two house rules of 2026-10-11: no grey tracker text
in the top corner, and line icons rather than emoji in the house look. Its trackers and
emoji glyphs are not the look; drop them when copying a slide. To rebuild it after a
change to the helpers:

```sh
NODE_PATH="$(npm root -g)" node assets/patterns_build.js "${SLIDE_TEMPLATES_DIR}/Consulting patterns - data and AI.pptx"
```

## Rules for using the templates directly

- Copy a slide out of a template only when its layout is the pattern and its text is
  placeholder (S, G, P). P carries no branding, so nothing needs stripping. The K deck's slides carry BCG client content and BCG branding: use
  them as references for look and density, never as copies.
- The template masters carry a BCG copyright footer rotated on the right edge and BCG
  logos on cover and back. Strip both from anything that leaves the house; the build path
  in `build.md` avoids them by reproducing the look in a clean file.
